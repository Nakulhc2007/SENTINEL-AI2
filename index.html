Required before a live connector can be built

  1. Identify the exact source system and its owner.
  2. Obtain written authorization, API documentation, and a sandbox endpoint.
  3. Define event fields, data minimization, retention, and incident escalation rules.
  4. Implement a server-side connector with secure secret storage and access controls.
  5. Validate in the approved sandbox, audit the integration, and obtain production approval.
ⓘ Live integration requires a secure backend and approved endpoints. Never put API keys or production credentials in this frontend.
